# K 마인드맵

폰에 설치해서 쓰는 마인드맵 + 메모장 앱 (PWA). 서버·계정 없이 동작하고, 데이터는 기기 안에만 저장됩니다. 오프라인에서도 사용할 수 있습니다.

## 기능
- 마인드맵 편집: 하위/형제 추가, 연속 입력(Enter), 색상, 메모, 체크박스, 접기/펼치기, 순서 이동, 들여쓰기, 복제
- 템플릿: 빈 맵 · 아이디어 메모 · 업무/프로젝트 · 여행 계획
- 💡 빠른 메모: 홈에서 바로 적으면 "아이디어 수첩" 맵에 쌓임
- 개요(목록) 보기, 검색, 실행 취소/다시 실행
- 내보내기: 이미지(PNG), 텍스트(마크다운), JSON 백업/복원
- 다크 모드 자동 지원

## 폰에 설치하기
앱 파일은 `public/` 폴더입니다. HTTPS 주소에 올려야 폰에서 "앱 설치"가 됩니다.

1. 이 저장소를 `main`에 머지하면 GitHub Actions가 자동 배포합니다.
2. GitHub 저장소 **Settings → Pages → Source: GitHub Actions** 로 설정합니다.
3. 폰에서 `https://<아이디>.github.io/K-MIND-MAP/` 를 엽니다.
   - Android(Chrome): 메뉴 ⋮ → **앱 설치 / 홈 화면에 추가**
   - iPhone(Safari): 공유 ⎙ → **홈 화면에 추가**

(Netlify·Cloudflare Pages 등에 `public/` 폴더를 올려도 됩니다.)

## 로컬 실행
```
cd public && python3 -m http.server 8000
```
